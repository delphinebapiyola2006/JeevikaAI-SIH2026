# Prototype datasets

These CSVs are included for the MVP and are not live government or vacancy feeds.

- `nsqf_roles.csv`: prototype role catalogue for matching logic. Verify current NSQF/QP/NOS references before submission.
- `opportunities.csv`: synthetic district-level livelihood signals used to demonstrate the Opportunity Map. They must be replaced with verified government/partner data before production.

The UI does not present these records as live vacancies.
