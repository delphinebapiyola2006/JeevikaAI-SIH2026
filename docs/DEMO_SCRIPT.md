# 3-minute demo

1. Open JeevikaAI.
2. Select Tamil.
3. Start Voice Assessment.
4. Say/type: “நான் பன்னிரண்டாம் வகுப்பு முடித்திருக்கிறேன். விவசாயம் செய்கிறேன். Solar installation கற்றுக்கொள்ள விரும்புகிறேன்.”
5. Show the structured beneficiary profile.
6. Generate recommendations.
7. Show role, NSQF level, match score, reasons, skill gaps and pathway.
8. Open Opportunity Map and explain that records are demo data.
9. Open Admin Analytics.
10. Explain React → FastAPI → database → recommendation engine.
