# PPT Content

## 1. Title
JeevikaAI — AI-Driven Voice Assistant for Livelihood Mapping and NSQF-Aligned Skilling Recommendations

## 2. Problem
- Digital and language barriers
- Difficulty identifying suitable skills and training
- Skill mismatch
- Need for local livelihood opportunity visibility

## 3. Solution
Voice-first conversational assistant that creates a profile, identifies skill gaps, maps to NSQF-aligned roles and connects recommendations to local opportunities.

## 4. Workflow
Voice → ASR → Profile → Skill Gap → NSQF Matching → Local Opportunity → Pathway → TTS

## 5. AI/ML
Speech recognition, multilingual processing, skill/interest extraction, semantic similarity, explainable weighted recommendation.

## 6. Modules
Voice Assessment, Profile Engine, NSQF Role Catalog, Skill Gap Engine, Recommendation Engine, Opportunity Map, Admin Analytics.

## 7. Technology
React, FastAPI, Python, SQLite/PostgreSQL, Web Speech API, optional BHASHINI, Leaflet/OpenStreetMap.

## 8. Impact
Accessible voice interaction, explainable skill pathways, local opportunity visibility, scalable multilingual architecture.

## 9. Future Scope
Verified live datasets, IVR, WhatsApp voice, more languages, verified training centers, outcome tracking.
